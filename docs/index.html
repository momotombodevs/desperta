Preguntas frecuentes

Preguntas frecuentes

¿Cómo funciona la alarma?

Elegís una hora y los días en que querés activarla. Cuando suena, Despertá abre un reto de tres preguntas para terminar la alarma.

¿Qué pasa si respondo mal una pregunta?

La alarma sigue activa. Podés intentar una nueva serie hasta completar correctamente las tres respuestas.

¿Qué es posponer?

Posponer vuelve a programar la alarma para más tarde. Esa ejecución se registra de forma distinta en tu progreso local.

¿Puedo elegir qué días se activa?

Sí. Podés configurar una alarma para días específicos o usarla una sola vez.

¿Cómo funciona el historial de 7 días?

El historial muestra tus ejecuciones recientes para ayudarte a identificar cómo van tus mañanas y tu racha.
